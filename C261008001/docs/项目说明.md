# 项目说明

## 1. 研究范围

系统研究电竞鼠标与电竞键盘，面向两类使用者：消费者使用偏好权重筛选商品，市场分析人员研究品牌、价格、规格、促销和评价热度。

核心页面包括数据概览、偏好分析、定价分析、促销分析、竞品对比、数据维护和系统验收。

## 2. 数据结构

SQLite 数据库位于 `data/esports_analysis.db`，主要表如下：

| 表 | 内容 |
|---|---|
| `products` | 商品、品牌、平台和链接 |
| `product_specs` | DPI、重量、回报率、轴体、配列等规格 |
| `price_snapshots` | 按日期保存的价格快照 |
| `sales_snapshots` | 评价数等热度代理指标 |
| `reviews` | 已脱敏的评论样本 |
| `preference_scores` | 可解释偏好评分 |
| `collection_jobs` | 数据导入任务记录 |

字段原则：未知值保存为 `NULL`；价格单位为人民币元，重量为克，频率为赫兹；时间使用带时区的 ISO 8601 字符串。

## 3. 数据来源与口径

- 历史价格：慢慢买公开查询页面，保存来源商品链接和采集日志。
- 京东、天猫商品：只处理目标清单内的少量公开商品页面。
- 产品规格：优先采用厂商官网，京东结构化属性作为补充。
- 评价热度：采用页面展示评价数的下限值，例如“1万+”记为 `10000`，同时保存原始文本。
- 评论：仅保存评论正文、评分、时间和商品规格；昵称、用户ID、头像和地区不入库。

价格、促销、评价数和评论均为观察值，不等同于实际成交价、实际销量或全量消费者意见。

## 4. 分析方法

- 偏好分析：按手感、响应、舒适度、耐用性、外观和性价比计算规则评分。
- 定价分析：比较价格带、历史最低价、价格波动率和同型号跨平台价差。
- 热度分析：以评价数下限作为代理变量，研究价格与市场关注度的关系。
- 评论分析：结合评分、关键词和评价标签提取情感倾向、关注维度与优缺点。

缺失参数使用中性分并明确标注；少量代表性评论不直接改变商品总排名，避免样本偏差被放大。

## 5. 数据质量与合规

- 不绕过验证码、登录限制或平台频控。
- 不采集账号凭证和用户身份字段。
- 不把推算值标注为真实销量。
- 同型号跨平台比较需要人工核对型号和规格。
- 采集失败保留为空值和错误日志，不用虚构值补齐。

运行 `python scripts/run_acceptance.py` 生成验收报告，运行 `python -m pytest -q` 验证代码逻辑。
